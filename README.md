# 恒指期货周期谐波震荡策略 (vn.py)

基于 vn.py CTA 框架的恒生指数期货多周期谐波震荡策略。

## 策略原理

通过 1 分钟 / 4 分钟 / 14 分钟三个周期的 KDJ 指标信号，按权重加权后判断方向，配合 ATR 追踪止损止盈。

- **短周期 (1min)**: 权重 1
- **中周期 (4min)**: 权重 3
- **长周期 (14min)**: 权重 9

信号得分 = 长周期×9 + 中周期×3 + 短周期×1 - 13

当得分 ≥ 2 时做多，≤ -2 时做空。

## 风控机制

- 追踪止损: 2 × ATR（只收紧不放松）
- 止盈: 1.5 × ATR
- 每日最大亏损: 1000 HKD
- 连续亏损 2 次后暂停 14 根长周期 K 线
- 定时平仓: 03:00 和 21:29

## 文件说明

| 文件 | 说明 |
|------|------|
| `period_harmonic_strategy.py` | 策略主文件（vn.py CTA 策略） |
| `backtest_hsi.py` | 离线回测启动脚本（CSV 直注方式） |

## 使用方式

### 离线回测

```bash
# 回测全量数据
python backtest_hsi.py

# 指定时间区间
python backtest_hsi.py 2024-01-01 2024-03-31
```

需要准备恒指期货 1 分钟 K 线 CSV 文件，列名为：时间、开盘价、最高价、最低价、收盘价、成交量。

修改 `backtest_hsi.py` 中的 `CSV_PATH` 指向你的数据文件。

### VeighNa Studio 实盘/模拟盘

1. 将 `period_harmonic_strategy.py` 放入 vn.py 策略目录
2. 在 VeighNa Studio 的 CTA 策略模块中添加策略
3. 配置参数并启动

## 合约参数

- 合约: HSImain.HKFE（恒指主连）
- 合约乘数: 50 HKD/点
- 最小变动价位: 1 点
- 手续费率: 0.000047
- 滑点: 1 点

## 修复说明

本版本修复了原 Futu 策略中的以下问题：

1. **KD 递推公式错误**: 原权重和为 0.75 导致信号衰减，改为标准 2/3 + 1/3
2. **持仓后阻断更新**: 重构 on_bar 流程，持仓时仍更新止损止盈
3. **止损方向错误**: 改为追踪止损（多头只上移不下移，空头只下移不上移）
4. **重采样时间边界**: 按交易日对齐重采样，避免跨交易日分组
5. **手动改持仓方向**: 移除手动方向设置，依赖 vn.py 引擎维护 self.pos
6. **反手交易不计入亏损**: on_trade 统一处理所有成交的盈亏统计
7. **每日亏损按自然日重置**: 改为 17:15 交易日切分（恒指夜盘归次日）
8. **订单重复提交**: 添加 order_pending 标志位防止重复下单

## 性能优化

- DATA_WINDOW 从 9600 降到 2000
- 信号冷却：每 14 根 K 线才重算长周期信号
- resample 用 np.maximum.reduceat 完全向量化
- ATR 只在信号重算时计算
