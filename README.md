# 恒指期货周期谐波震荡策略 (vn.py)

基于 vn.py CTA 框架的恒生指数期货三周期分层共振策略。

## 策略原理

通过 1 分钟 / 4 分钟 / 14 分钟三个周期分层判断，各周期承担不同职责：

- **14 分钟（长周期）**: 判断主要趋势方向
- **4 分钟（中周期）**: 确认趋势，必须与 14 分钟同向才形成可交易环境
- **1 分钟（短周期）**: 选择进场时机，从中性或反向切换到高周期方向时触发入场

### KD 信号标准化

每个周期的 KD 信号转换为方向值：

| KD 状态 | 方向值 | 含义 |
|---------|--------|------|
| K >= 80 且 K >= D | +1 | 多头（动量延续） |
| K <= 20 且 K <= D | -1 | 空头 |
| 其他 | 0 | 中性 |

### 入场条件

多单进场（空单完全对称）：
1. 14 分钟为多头 (+1)
2. 4 分钟也为多头 (+1)
3. 上一根 1 分钟信号不是多头
4. 当前 1 分钟信号刚刚变为多头 (+1)
5. 当前空仓，无未完成订单，无风控限制

### 退出条件

- **14 分钟反转**: 多头转空 → 平多仓（不立即反手，新方向需重新经过 4 分钟确认 + 1 分钟触发）
- **14 分钟中性**: 不主动平仓，继续由止损/止盈/定时管理
- **4 分钟或 1 分钟反向**: 不主动平仓

## 风控机制

- 追踪止损: 2 × ATR（只收紧不放松，预挂停止单确保跳空成交）
- 止盈: 1.5 × ATR（开仓时固定，不随价格更新）
- 每日最大亏损: 1000 HKD
- 连续亏损 2 次后暂停 14×14=196 根 1 分钟 K 线
- 定时平仓: 03:00 和 21:29（收盘后 5 分钟禁止重开）
- 限价单超时: 2 根 K 线未成交自动撤单

| 文件 | 说明 |

| `period_harmonic_strategy.py` | 策略主文件（vn.py CTA 策略 v3.2） |
| `backtest_hsi.py` | 离线回测启动脚本（CSV 直注方式） |

## 使用方式

### 离线回测

```bash
# 回测全量数据
python backtest_hsi.py

# 指定时间区间
python backtest_hsi.py 2024-01-01 2024-03-31

# 指定CSV文件路径
python backtest_hsi.py 2024-01-01 2024-03-31 --csv /path/to/HSI.csv
```

需要准备恒指期货 1 分钟 K 线 CSV 文件，列名为：时间、开盘价、最高价、最低价、收盘价、成交量。

修改 `backtest_hsi.py` 中的 `CSV_PATH` 指向你的数据文件，或使用 `--csv` 参数。

### VeighNa Studio 实盘/模拟盘

1. 将 `period_harmonic_strategy.py` 放入 vn.py 策略目录
2. 在 VeighNa Studio 的 CTA 策略模块中添加策略
3. 配置参数并启动

## 合约参数

- 合约: HSImain.HKFE（恒指主连）
- 合约乘数: 50 HKD/点
- 最小变动价位: 1 点
- 手续费率: 0.000047
- 滑点: 1 点

## 修复说明

### v3.2 重构 (基于 Codex 第三轮审查)

1. **三周期分层共振**: 取消 9/3/1 加权评分，改为分层状态机：14 分钟定趋势、4 分钟确认、1 分钟触发入场
2. **短周期真正参与决策**: 1 分钟从中性/反向切换到同向时触发入场，持续同向不重复开仓
3. **14 分钟反转只平仓不反手**: 新方向需重新经过 4 分钟确认 + 1 分钟触发
4. **重采样午休间隙**: 午休后加 60 分钟偏移，不再跨午休拼接 K 线
5. **丢弃不完整 K 线组**: resample 内部按组大小过滤，不再粗暴截断
6. **止损预挂停止单**: 开仓成交后预挂止损止盈单，vn.py 引擎在 on_bar 前自动撮合
7. **止损上移更新**: 撤旧单挂新单，确保追踪止损生效
8. **限价单超时撤单**: 2 根 K 线未成交自动撤单，防止 order_pending 永久锁死
9. **多笔成交盈亏记账**: 累积加权均价 + 枚举比较，支持部分成交
10. **枚举比较替代字符串匹配**: 使用 Direction/Offset/Status 枚举，更稳定
